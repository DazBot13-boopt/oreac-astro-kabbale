# Pack Windows classique (Delphi)

Placez ici l’exécutable **`Astrologie & Horoscope.exe`** (et son dossier de données si besoin) pour que le bouton « Lancer » du module classique fonctionne sous Electron Windows.

Sur le VPS de build / dépôt lourd :

```text
/opt/oreac-legacy/
```

Copiez ce dossier à côté de l’installateur OREAC ou définissez `OREAC_LEGACY_DIR`.

Ne committez pas les binaires (~140 Mo) dans Git.
