# OREAC Astro Kabbale

Application d’astrologie kabbalistique hors ligne : thème natal, Arbre de Vie, anges, carte du ciel, calendrier des degrés symboliques, biorythme personnalisé et export PDF.

## Fichiers principaux

- `index.html` — client principal
- `biorythme.html` — biorythme kabbalistique (personnalisé au nom du client)
- `admin.html` — édition des interprétations
- `js/` — logique, données embarquées, police
- `fonts/StarFisher.ttf` — glyphes astrologiques
- `vendor/` — Astronomy Engine + jsPDF

## Utilisation

Ouvrir `index.html` dans un navigateur (fichier local). Remplir le thème, calculer, puis éventuellement ouvrir le biorythme personnalisé.
